👩‍💻 Project Description

Froman Workspace is an interactive portfolio website designed to represent a modern and creative digital workspace through a combination of frontend development and 3D visualization technologies.

The project integrates an explorable 3D setup modeled in Blender directly into the browser using <model-viewer>, allowing users to interact with the environment in real time through rotation, zoom, and immersive exploration features.

Unlike traditional portfolios, this project focuses on creating a more personal and visually expressive experience inspired by the concept of a Cozy Tech Workspace — an environment that combines comfort, creativity, productivity, and technology.

The portfolio also showcases personal projects, interactive previews, modern UI design, responsive layouts, and smooth user interactions to create a professional yet authentic digital identity.
